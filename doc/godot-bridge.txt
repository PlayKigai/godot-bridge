*godot-bridge.txt*          GDScript in Neovim via the Godot editor's own
                            language server and debugger. Backed by the
                            `godot-bridge` CLI.

==============================================================================
INTRODUCTION                                          *godot-bridge-intro*

This plugin wires Neovim to the `godot-bridge` binary from
https://github.com/PlayKigai/godot-bridge. It provides an LSP client for GDScript, run/editor/doc
commands, and optional nvim-dap debugging. Neovim 0.10 or later. The only
optional dependency is nvim-dap, required just for |godot-bridge-dap|.

The bridge can be downloaded with `:GodotBridgeInstall`, or installed
by hand (needed on other platforms):
>
    cargo install godot-bridge --locked
<
See |godot-bridge-install|.

Install with lazy.nvim:
>
    {
      "PlayKigai/godot-bridge",
      ft = "gdscript",
      opts = {},
    }
<
lazy.nvim calls `require("godot-bridge").setup(opts)` for you.

==============================================================================
SETUP                                                     *godot-bridge-setup*

The language server starts only after `require("godot-bridge").setup()`;
the commands work with defaults without it.

>
    require("godot-bridge").setup({
      bridge_path = "godot-bridge",      -- name on PATH, or a path (~/ and home-relative allowed).
                                         -- A path setting wins; otherwise the file from
                                         -- |godot-bridge-install| wins over PATH.
      settings = {                       -- sent verbatim as JSON, see below
        project_diagnostics = false,
      },
    })
<

On setup the plugin runs `godot-bridge --version` asynchronously and
warns if it fails or the major.minor differs from the plugin's version. Run
`:GodotBridgeInstall` or `cargo install godot-bridge --locked` to fix that.
On macOS the bridge is unsupported (`macOS is not supported. Linux and
Windows only.`); an error is shown and nothing else happens.

Settings (all optional; only keys you set are sent):
>
    godot_path            string   godot binary path, default $GODOT, else godot4 or godot on PATH
    project_dir           string   dir containing project.godot, relative to root
    lsp_port              integer  attach to an editor you started yourself
    dap_port              integer  debug port, used only with lsp_port, default 6006
    project_diagnostics   bool     diagnostics for all scripts, default true
    diagnose_addons       bool     include addons/, default false
    exclude               string[] globs kept out of the project-wide
                                   diagnostics and symbol scan and scene lookup,
                                   default empty. A bare name matches at any
                                   depth, a / or ./ before the name anchors to
                                   the project root except a leading **/, a
                                   trailing / matches directories only. *, ?
                                   and **, no negation
    extra_args            string[] extra Godot flags
    startup_timeout_s     integer  how long to wait for Godot, default 600
<
On FileType gdscript the plugin finds the project root by searching upward
for `project.godot`. One LSP client runs per root.

==============================================================================
COMMANDS                                                  *godot-bridge-commands*

:GodotRun                    Run the project.
:GodotRunScene               Run the scene of the current file.
:GodotEditor                 Swap headless Godot for the GUI editor.
:GodotDoc [symbol]           Open class reference. Defaults to the word under
                             the cursor (dots included).
:GodotStatus                 Print bridge status.
:GodotRestart                Stop the client for the current root and start
                             it again.
:GodotBridgeInstall          Download and install the bridge, see
                             |godot-bridge-install|.

Commands run in the project root and report output on exit.

==============================================================================
INSTALL                                               *godot-bridge-install*

:GodotBridgeInstall downloads the prebuilt bridge for this plugin's
version (x86_64/aarch64 Linux and Windows) from the release tagged with
the plugin version, verifies its SHA-256 against that release's
SHA256SUMS, and stores it under Neovim's data directory: >
    <stdpath("data")>/godot-bridge/godot-bridge-vX.Y.Z-<arch>-<os>
<Use `:echo stdpath("data")` to see the directory. Requires `curl`, plus
`sha256sum` on Linux or `certutil` on Windows. `setup()` never downloads;
run this command explicitly. A second call while one runs is rejected.
To go back to a PATH bridge, delete the stored file or set `bridge_path`
to a path.

==============================================================================
DAP                                                   *godot-bridge-dap*

Requires nvim-dap. Call after `require("godot-bridge").setup(...)`:
>
    require("godot-bridge").dap()
<
Registers the `godot` adapter and the `gdscript` configurations:
>
    Godot: run project        launch, scene "main"
    Godot: run current scene  launch, scene "current"
    Godot: attach             attach
<
The adapter passes the current buffer path as `--file`, needed for
`scene: "current"`. The `lsp` for the same project must already be running.
