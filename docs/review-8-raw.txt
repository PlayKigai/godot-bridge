1. Quote: “Read the client's `initialize` request first and hold it.” / “Buffer further client messages, at most 64 MiB, until connected.”

**Phase 3**

3. Quote: “A deleted file keeps its entry until `didClose` is processed.” / “Every file URI from Zed ... passes through the shared path-to-URI function before lookup.”

Problem: Filesystem canonicalization fails after deletion. A Zed URI using a symlink or alternate spelling can no longer recover the existing canonical key, so implementations may leak or duplicate the document entry.

Exact fix text: “When processing a successful Zed `didOpen`, retain a mapping from the normalized incoming URI to its canonical document key. Use that mapping for subsequent `didChange` and `didClose`, including after the file is deleted. Remove the mapping when the document is finally forgotten.”

4. Quote: “After step 8 of startup ... the bridge lists every `.gd` ... and ... sends `didOpen`.”

Problem: Step 8 returns the `initialize` response, but Zed has not necessarily sent `initialized`. Implementers may send synthetic `didOpen` notifications before LSP initialization completes.

Exact fix text: “On initial startup, begin project-wide `didOpen` and `documentSymbol` traffic only after forwarding Zed’s `initialized` notification to Godot. Recovery continues to send bridge-generated `initialized` before replaying documents.”

**Phase 4**

5. Quote: A reconnecting `lsp` “writes its own owner identity ... waits for both ports” and, on timeout, exits while the “GUI [is] left alone.”

Problem: Timeout leaves state naming the now-dead bridge as owner. Later stale-state cleanup can remove valid detached-GUI state, contradicting the rule that a live GUI must not be replaced solely because its ports are unavailable.

Exact fix text: “During detached-GUI reconnection, keep `owner_pid` and `owner_start_ticks` null until both ports are ready. Bind the socket and publish the new owner identity only after readiness succeeds. On failure, remove the socket, preserve the detached GUI state with null owner fields, and leave the GUI running.”
